# MORIMUR BABY 手機導覽與品牌資產設計

## 目標

將商城前台與老闆後台的手機版導覽改為漢堡選單，避免多欄連結長期佔據畫面；同時以使用者提供的 MORIMUR BABY 圓形徽章取代現有 mori 文字標誌與 favicon。桌機版既有導覽結構維持不變。

## 品牌資產

- 來源：使用者提供的 `codex-clipboard-86236680-ba4e-4f5d-a3ac-2e42acaa88b5.png`。
- 作法：以確定性的圖片裁切與縮放保留原圖，不使用生成式重繪，避免改變圖中文字、人物、樹木與色彩。
- 裁切：以原圖圓章為中心裁成正方形，移除圓章外過多的白色留白，但保留完整灰色外圈。
- 網站 LOGO：輸出適合高解析螢幕的 PNG，在前台、會員區、頁尾與後台共用。
- favicon：從同一裁切結果輸出正方形小圖，交由 Next.js metadata 圖示機制提供。
- 圖片替代文字：可點擊的品牌連結保留描述性 `aria-label`；圖片本身視為裝飾，避免重複朗讀。

## 前台手機導覽

### 收合狀態

- 只顯示一列主要操作：漢堡按鈕、圓形品牌徽章、購物車及既有必要快捷操作。
- 商品分類、品牌故事、搜尋與會員功能不再常駐換行顯示。
- 公告列保留在導覽上方。

### 展開狀態

- 選單由畫面右側滑入，搭配半透明遮罩。
- 抽屜包含：新品、所有商品、依年齡、全部分類、品牌故事、商品搜尋、會員登入／會員中心、訪客查單與老闆後台入口。
- 點擊關閉按鈕、遮罩、導覽連結或按下 Escape 都可關閉。
- 開啟時將焦點移入抽屜；關閉時將焦點還給漢堡按鈕。
- 手機抽屜與既有購物車抽屜不得互相覆蓋或造成無法操作。

## 後台手機導覽

### 收合狀態

- 原本固定展開的後台側欄改為緊湊頂列。
- 頂列顯示圓形品牌徽章、「商店後台」識別與漢堡按鈕。
- 後台內容從頂列下方開始，不保留桌機側欄寬度。

### 展開狀態

- 使用與前台一致的右側抽屜互動與動畫語言。
- 保留完整管理入口：商店總覽、訂單、商品與庫存、分類、會員、行銷、報表、設定、返回商城及登出。
- 抽屜顯示目前老闆身分資訊，但不在收合狀態佔用畫面。

## 桌機行為

- 前台在既有桌機斷點以上維持完整水平導覽。
- 後台在既有桌機斷點以上維持固定左側欄。
- 漢堡按鈕與手機抽屜只在小螢幕出現，不建立第二套桌機資訊架構。

## 元件邊界

- 建立可重用的 client-side 手機抽屜元件，集中處理開關、Escape、遮罩、焦點回復及捲動鎖定。
- `SiteHeader` 負責前台連結內容與購物車／會員操作，不自行重複抽屜狀態邏輯。
- `AdminLayout` 負責後台連結與登出內容，沿用相同抽屜介面。
- `BrandLogo` 改為共用圖片資產呈現，維持現有呼叫端可設定用途描述的介面或以最小相容調整替換。

## 視覺與動態

- 沿用現有森林綠、紙張白與細線框架，不新增與品牌徽章競爭的裝飾。
- 漢堡按鈕至少 44 × 44 CSS pixels，三條線在展開時可轉為關閉符號。
- 抽屜寬度以手機可讀性為準，最大不超過 viewport；內容過長時只在抽屜內垂直捲動。
- 遵守 `prefers-reduced-motion`，減少動態時取消滑入與圖示旋轉動畫。

## 無障礙

- 漢堡按鈕使用真實 `button`，提供 `aria-expanded`、`aria-controls` 與「開啟／關閉選單」名稱。
- 抽屜具有可辨識的導覽標籤，關閉按鈕具明確名稱。
- 所有互動元件保留明顯 `:focus-visible` 樣式。
- 抽屜開啟時避免背景內容被鍵盤誤操作，並支援 Escape 關閉與焦點回復。

## 驗證標準

- 375 × 812 前台首頁、商品頁與購物車頁無水平溢出。
- 375 × 812 後台總覽、訂單與商品頁無水平溢出。
- 前後台漢堡按鈕能開啟及關閉各自抽屜；Escape、遮罩與導覽連結關閉行為正常。
- 桌機前台導覽與後台側欄仍正常顯示。
- 品牌徽章在前台、會員區、頁尾及後台正確顯示；favicon 可由 `/icon` 或 Next.js 產生的圖示路徑載入。
- Lint、TypeScript、相關單元測試、375px Playwright 測試及 production build 通過。

## 非目標

- 不重新設計品牌徽章，不修改徽章內文字或插畫。
- 不改動桌機資訊架構、商品功能、付款流程、會員權限或後台資料功能。
- 不新增第三方選單函式庫或圖示套件。
