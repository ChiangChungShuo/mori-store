# MORIMUR BABY 手機頂列、導覽與 Footer 調整設計

日期：2026-07-22

## 目標

調整前台與後台手機版頂列，使操作按鈕、品牌 Logo 與購物車視覺對齊；將前後台漢堡抽屜統一改為從左側開啟；精簡前台選單內容，並縮小 Footer Logo、改善品牌標語排列。

本次只調整導覽、搜尋入口、會員入口、購物車圖示與 Footer 品牌區，不改動商品、購物車資料、會員權限、付款或訂單流程。

## 已選方案

手機前台採用 C「左右群組」：左側放漢堡與搜尋，中央放 Logo，右側放會員與購物車。左右兩組使用相同寬度，Logo 獨立置中，不由左右內容寬度決定位置。

曾評估的替代方案：

- 五項平均單列：結構直接，但 Logo 容易被左右操作拉偏。
- 上下雙列：操作空間最大，但增加頂列高度並壓縮首屏內容。
- 左右群組：最接近參考網站，保留單列高度並提供所有外層入口，因此採用此方案。

## 前台手機頂列

### 排列

頂列在 375px 寬度仍保持單列：

```text
[漢堡][搜尋]        [Logo]        [會員][購物車]
```

- 左、右操作群組寬度相同。
- Logo 使用獨立置中方式，顯示尺寸為 48–52 CSS pixels。
- 每個圖示按鈕至少有 44 × 44 CSS pixels 可點擊範圍。
- 行動版頂列不得水平溢出；桌機版既有導覽維持不變。

### 搜尋

- 點擊搜尋圖示後，在頂列正下方展開搜尋列。
- 搜尋列包含可辨識的文字標籤、輸入框、送出按鈕與關閉按鈕。
- 送出後沿用既有商品搜尋路由與 query 參數，不建立新的搜尋資料流程。
- 再次點擊搜尋圖示、按 Escape 或按關閉按鈕會收合搜尋列。
- 展開時將焦點移至輸入框；關閉後將焦點還給搜尋圖示。

### 會員入口

- 會員圖示是直接連結，不再於手機頂列開啟會員下拉選單。
- 已登入時連至 `/account`。
- 未登入時連至 `/login`，並保留可回到會員中心的既有導向方式。
- 使用可辨識的 `aria-label`，不以圖示形狀作為唯一名稱。

### 購物車

- 保留既有購物車抽屜、商品數量、總額與結帳功能。
- 將圖示改為簡潔的線條 SVG 購物車，筆畫、尺寸與搜尋／會員圖示一致。
- 數量徽章固定於購物車按鈕右上角，不改變頂列高度或推動其他項目。
- 加入商品時的既有動畫與數量更新維持不變。

## 前台手機導覽抽屜

- 漢堡位於頂列左側。
- 抽屜由畫面左側滑入，遮罩覆蓋其餘畫面。
- 面板陰影與邊框方向配合左側抽屜，不沿用右側面板的視覺方向。
- 關閉按鈕位於抽屜右上角。
- 保留 Escape、遮罩點擊、導覽連結點擊關閉與焦點返回。
- 保留內部垂直捲動及 `prefers-reduced-motion` 支援。

### 選單內容

- 主要連結保留新品、所有商品、依年齡與品牌故事。
- 搜尋與會員中心移出抽屜，不在選單內重複顯示。
- 商品分類改為原生可展開區塊，預設收合。
- 分類標題顯示目前用途與展開狀態；點擊後才顯示分類連結。
- 分類清單沿用目前已發布商品的動態分類與既有預設分類備援。
- 訪客訂單查詢與老闆後台入口保留在抽屜的服務區。

## 後台手機頂列與抽屜

後台使用與前台相同的高度、左右安全距離、44px 控制尺寸與中央 Logo 對齊規則：

```text
[漢堡]             [Logo]             [老闆會員]
```

- 漢堡位於左側，抽屜由左側滑入。
- Logo 顯示尺寸與前台一致。
- 右側老闆會員圖示連至 `/admin`，並提供「商店後台首頁」的無障礙名稱。
- 「商店後台」文字不再佔據中央 Logo 位置。
- 抽屜保留所有後台功能連結、管理員資訊、返回商城與登出。
- 768px 平板與桌機既有後台側欄行為維持不變。

## Footer 品牌區

- 縮小 Footer Logo，不再以大型獨立區塊佔據品牌區上方。
- Logo 放在「把舒服穿進每一天的成長」標語左側，文案與原有介紹、連結置於右側。
- 桌機與手機皆維持 Logo 左、文字右；手機版縮小間距與字級，但不改成大型上下堆疊。
- Logo 保持完整圓形比例，不裁切徽章文字或插畫。
- 購物指南、會員服務、配送資訊與 Footer 底部連結內容不變。

## 元件邊界

- `SiteHeader` 負責前台手機頂列排列、搜尋展開狀態與會員直接連結。
- `MobileMenu` 增加抽屜方向介面，前後台皆指定左側；元件持續負責 dialog、焦點與關閉行為。
- 前台選單內容負責分類收合結構，不把分類狀態放進共用 `MobileMenu`。
- `CartDrawer` 只更換觸發圖示與行動版定位，不更動購物車資料邏輯。
- `AdminLayout` 負責後台手機頂列三區內容。
- `SiteFooter` 負責新的 Logo 與標語水平品牌鎖定排列。

## 錯誤與退化處理

- 搜尋輸入為空時仍沿用現有商品列表行為，不新增阻擋流程。
- 尚未取得使用者資訊時，會員圖示使用未登入連結，避免產生無效按鈕。
- 沒有動態分類資料時顯示既有預設分類。
- 圖示使用內嵌 SVG，不依賴第三方 icon 套件或網路資源。

## 驗收標準

- 375 × 812 前台頂列的左右群組、中央 Logo 與各按鈕對齊，無水平溢出。
- 375 × 812 後台頂列顯示左側漢堡、中央 Logo、右側老闆會員圖示，無水平溢出。
- 前後台抽屜皆由左側開啟，關閉與焦點返回行為正常。
- 前台分類預設收合，點擊後才顯示完整分類，且可再次收合。
- 搜尋列可由頂列圖示展開，焦點進入輸入框，送出可到商品搜尋結果。
- 已登入與未登入會員圖示分別連到正確頁面。
- 購物車 SVG、數量徽章、開啟抽屜與加入商品動畫正常。
- Footer Logo 縮小並顯示於標語左側，徽章不變形。
- 768px 與 1440px 的桌機導覽、後台側欄及 Footer 不因手機調整而破壞。
- ESLint、TypeScript、相關 Vitest 與 Playwright 驗證通過；既有且與本次無關的失敗需分開記錄。
