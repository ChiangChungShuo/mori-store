# 商品分類與系列導覽設計

日期：2026-07-31

## 目標

在既有「上衣、褲子、洋裝」等商品分類下增加第二層「系列」，讓顧客能從分類進一步查看該分類的全部商品或特定系列，例如「Mori flora 漫花系列」。老闆可在後台自行新增、刪除及排序系列，並讓同一商品同時屬於多個系列。

## 已確認規則

- 系列隸屬單一分類，不跨分類共用。
- 商品可以同時勾選目前分類下的多個系列。
- 同一分類內的系列名稱不可重複，不同分類可使用相同名稱。
- 系列名稱最多 40 個字。
- 現有商品預設沒有系列，不影響既有前台、庫存或訂單資料。
- 已被商品使用的系列不可直接刪除，需先移除商品關聯。
- 商品更換分類時，原分類的系列關聯會清除。

## 資料設計

新增 `product_series`：

- `id`：UUID 主鍵。
- `category_name`：所屬分類名稱，與既有分類資料連動。
- `name`：系列顯示名稱。
- `position`：同分類內的顯示順序。
- `created_at`、`updated_at`。
- 同分類內以不分大小寫方式限制名稱唯一。

新增 `product_series_products` 多對多關聯表：

- `product_id`：商品。
- `series_id`：系列。
- `(product_id, series_id)` 為複合主鍵。
- 商品刪除時一併刪除關聯，不影響訂單快照。
- 系列仍被商品使用時禁止刪除；移除全部商品關聯後才可刪除系列。

資料庫與伺服器端都要驗證商品分類與系列分類一致，避免直接呼叫 API 寫入錯誤關聯。系列資料沿用現有管理後台的管理員權限，不提供顧客修改權限。

## 後台管理

### 商品分類與預設值頁

在既有分類管理下方增加「系列管理」區：

1. 先選擇分類。
2. 顯示該分類目前的系列與順序。
3. 可新增系列。
4. 可上移、下移調整順序。
5. 可刪除未被商品使用的系列。
6. 被使用中的系列顯示明確提示，不執行刪除。

### 商品新增與編輯頁

- 在「分類」欄位下方增加「商品系列」多選控制。
- 尚未選分類時提示先選分類。
- 選定分類後，只列出該分類的系列。
- 沒有系列時顯示「此分類尚未建立系列」，並提供前往系列管理頁的連結。
- 商品可不選系列，也可選擇多個系列。
- 更換分類時立即清除不相容的既有選擇，儲存時再次由伺服器驗證。
- 草稿資料保留已選系列；完成建立商品時同步建立正式關聯。

## 前台桌機導覽

「全部分類」展開後改為雙欄面板：

```text
商品分類              選擇系列
上衣（目前選取）  →   全部上衣
褲子                  Mori flora 漫花系列
洋裝                  Mori forest 森林系列
外套
```

- 左欄使用可鍵盤操作的分類按鈕，選取時以現有淡藍色系標示。
- 右欄第一項固定是「全部＋分類名稱」，其後依 `position` 顯示系列。
- 點「全部上衣」前往 `/products?category=上衣`。
- 點系列前往 `/products?category=上衣&series=Mori%20flora%20漫花系列`。
- 沒有系列的分類，右欄只顯示全部分類商品入口。
- 點擊導覽連結後沿用既有自動關閉選單行為。

## 前台手機導覽

- 漢堡選單中的「商品分類」維持可收合。
- 每個分類增加第二層收合內容。
- 第二層第一項是該分類全部商品，其後顯示該分類系列。
- 選擇後前往商品列表並關閉漢堡選單。
- 收合控制具備正確的按鈕、焦點與展開狀態，避免只靠滑鼠或 hover。

## 商品列表與篩選

- URL 新增 `series` 查詢參數，必須與 `category` 一起使用。
- URL 只有 `series`、沒有 `category` 時忽略系列條件，回到全部商品。
- 商品查詢同時套用分類與系列關聯條件。
- E2E fixture 與正式 Supabase 查詢保持相同行為。
- 商品列表上方保留分類列；選定分類後，顯示第二列系列切換：
  - 全部該分類
  - 該分類的系列
- 搜尋、年齡、尺寸、顏色、庫存等既有篩選可與系列一起使用。
- 其他篩選送出時保留目前的分類與系列；清除條件則返回全部商品。
- 無符合商品時沿用既有空狀態，文案提示可改選其他系列或清除條件。

## 視覺方向

- 沿用 MORIMUR BABY 現有淡藍灰、白色與深色文字，不建立新的色彩系統。
- 雙欄面板以清楚的分類／系列層級為主，不加入多餘圖示或裝飾。
- 分類選取使用淡藍底與深色文字；系列連結使用細分隔線和適度留白。
- 桌機面板寬度需容納中英文系列名稱；手機維持單欄並避免橫向捲動。

## 失敗與邊界狀態

- 不存在或不屬於該分類的 `series` 參數不造成錯誤，顯示該分類沒有符合條件的商品。
- 系列新增重複時顯示「這個分類已有相同系列」。
- 刪除使用中的系列時顯示「仍有商品使用此系列，請先調整商品系列」。
- 商品儲存遇到不相容系列時拒絕儲存並提示重新選擇。
- 分類刪除仍遵守既有「有商品使用就不可刪除」規則；有系列時也不可刪除。

## 測試與驗收

- Migration 測試：資料表、唯一限制、索引、外鍵、RLS 與管理員操作函式。
- 後台測試：新增、重複、排序、刪除及使用中不可刪除。
- 商品測試：同分類多選、切換分類清除、建立與編輯後關聯正確。
- 查詢測試：只用分類、分類加系列、系列與其他篩選組合。
- 導覽測試：桌機雙欄切換、鍵盤操作、手機兩層收合與選取後關閉。
- 響應式驗收：桌機、手機無水平溢出，系列長名稱不破版。
- 正式資料庫套用 migration 後執行 schema lint、安全 advisor 與查詢驗證。

## 不在本次範圍

- 系列專屬形象頁、封面圖、介紹文章或活動頁。
- 跨分類共用同一系列。
- 商品卡直接顯示所有系列標籤。
- 以拖曳方式排序；本次使用明確的上移／下移操作。
