# 商品頁縮版與顏色圖片切換設計

## 目標

讓桌機版商品頁在一般筆電螢幕上更容易同時看到完整主圖與主要購買資訊，並讓顧客點選商品顏色時，立即看到該顏色的對應照片。

## 已確認範圍

- 縮小桌機版商品首屏的圖片、標題與欄距，維持現有 mori 淡藍灰色系與排版語氣。
- 商品圖片使用完整顯示，避免因圖片比例不同而裁掉衣服。
- 後台可為每一張商品圖片指定一個商品顏色，或標記為「共用圖片」。
- 前台點選顏色後，主圖與縮圖清單優先顯示該顏色圖片，再顯示共用圖片。
- 加入購物車時，使用目前選擇顏色的第一張圖片。
- 維持既有圖片排序、放大檢視、左右切換、手機滑動與刪除功能。

## 不在本次範圍

- 不建立獨立色票管理系統。
- 不依圖片內容或檔名自動猜測顏色。
- 不調整商品卡片、購物車或結帳頁的整體版型。
- 不變更商品規格的顏色輸入方式。

## 商品頁版型

桌機版商品區維持左右雙欄，但縮小最大內容寬度、圖片寬度、欄距與商品名稱字級。主圖容器以約 29rem 為上限，並限制在一般視窗高度內；圖片使用 `object-fit: contain`，確保整件商品可見。右側資訊仍依序保留商品名稱、價格、描述、收藏、寄送付款資訊、顏色、尺寸與加入購物車。

平板與手機版維持單欄。手機圖片仍可使用可用寬度，不因桌機縮版而變得過小；觸控滑動與縮圖列保持可操作。

## 圖片與顏色資料

在 `product_images` 增加可為空的 `color` 欄位：

- 有值：圖片只屬於該顏色，文字須與商品規格的顏色一致。
- 空值：共用圖片，可用於布料細節、尺寸說明或所有顏色共用的情境照。
- 現有圖片在資料更新後全部保持空值，因此不會遺失或停止顯示。

顏色仍以商品規格為來源，不另外建立顏色資料表。若老闆日後修改規格顏色名稱，舊圖片設定若無法配對，後台會保留原值並提示重新選擇，不會刪除圖片。

## 後台操作

### 建立商品

選取多張圖片後，每張預覽圖下方顯示「對應顏色」選單。選項來自目前已填寫的商品規格顏色，並包含「共用圖片」。建立商品時，圖片、順序、圖片說明與顏色設定一起儲存。

### 編輯商品

商品圖片卡片增加「對應顏色」選單。變更後立即儲存並顯示成功或失敗訊息，不需要重新上傳圖片。新增圖片時，也可在上傳前選擇顏色或共用圖片。

圖片排序只改變 `position`，不改變顏色。刪除圖片維持既有確認流程。

## 前台互動

商品頁由一個共用的顏色選取狀態連接圖片輪播與規格選擇器：

1. 初次進入時，預選第一個商品顏色。
2. 若該顏色有專屬圖片，輪播清單為「該顏色圖片（依原順序）」加上「共用圖片（依原順序）」。
3. 主圖自動顯示該顏色的第一張專屬圖片。
4. 顧客切換顏色時，尺寸選擇清空，圖片立即切換。
5. 若該顏色沒有專屬圖片，輪播維持顯示全部原始圖片，避免空白畫面。
6. 加入購物車時，商品圖片使用目前輪播清單的第一張；若不存在則沿用商品主圖。

圖片切換使用短暫淡入效果，並遵守使用者的減少動態效果設定。

## 資料流與相容性

- 商品查詢、後台商品查詢與購物車所需資料都讀取圖片顏色。
- 型別中的商品圖片增加 `color: string | null`。
- 圖片上傳、建立商品及圖片顏色更新都在伺服器端驗證管理員身分。
- 儲存圖片顏色前，確認該值存在於商品目前的有效規格顏色中；空值代表共用圖片。
- 舊商品與測試資料缺少顏色時，以 `null` 處理，不影響現有顯示。

## 錯誤處理

- 顏色已不存在：拒絕新設定並提示先確認商品規格。
- 儲存失敗：後台保留畫面原值，顯示失敗訊息，可重新操作。
- 商品沒有圖片：維持現有 mori 圖片預留畫面。
- 商品顏色沒有圖片：回退到完整圖片清單。

## 驗證標準

- 桌機商品頁首屏可看見完整主圖，圖片不被裁切，右側購買資訊仍清楚可讀。
- 手機版維持單欄，圖片、顏色、尺寸與加入購物車皆可操作。
- 後台可為新圖片及既有圖片設定、修改與清除顏色。
- 點選每個顏色時，主圖與縮圖只優先顯示該顏色及共用圖片。
- 沒有專屬圖片的顏色能正常回退，不出現空白或錯誤。
- 購物車顯示所選顏色的圖片。
- 相關單元測試、整合測試、瀏覽器測試、正式建置全部通過。
- 資料庫更新先進行 dry-run，再套用正式環境；正式部署需顯示 Vercel Ready 並切換至 `moribebe.com`。
